# Stickman Fighting Game Using ANN

## Project Description
This project is a simple 2D stickman fighting game developed
using Python and Pygame.

An Artificial Neural Network (ANN) is implemented using
Scikit-learn to select the enemy's actions.

## Features
- Player movement and attacks
- AI enemy with Attack, Defend and Move actions
- Player and enemy health bars
- Restart option
- ANN trained on generated example data

## Technologies Used
- Python
- Pygame
- NumPy
- Scikit-learn
- Artificial Neural Network (MLPClassifier)

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the game:

   python stickman_game.py

## Controls
- A: Move left
- D: Move right
- F: Attack
- R: Restart
- ESC: Exit

## Note
The ANN is trained on generated example data.
Its behaviour is a basic demonstration of machine-learning
classification, not a complex or independently learning game AI.
